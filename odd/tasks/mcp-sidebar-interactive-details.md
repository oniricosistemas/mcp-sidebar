# MCP Sidebar Interactive Details
Objective: Add theme-native MCP row interaction and an accessible tool-details view without replacing Pi's built-in `/mcp`.
Branch: `feat/interactive-mcp-details` · Test runner: Node test runner + TypeScript typecheck · Delivery: undecided

## Specs

1. **S1 — Namespace tool drill-down.** Preserve the request verbatim: “No habíamos dicho de hacer que si haciamos click en algun mcp del listado se abra una ventana con el listado y descripción de las tools?” Check: in fullscreen TUI, clicking a visible MCP namespace opens one bounded, scrollable modal listing that namespace's tool names and descriptions; the passive sidebar keeps normal editor focus.

Check: `/mcp-tools [namespace]` opens a namespace directly, `/mcp-tools` offers all available namespaces, unknown input is reported, and cancel makes no state change.
